# Third-party components and data

This project uses PyTorch, TorchVision, OpenCV, Ultralytics, Streamlit and ReportLab. It also includes model artifacts derived from or used with third-party datasets/checkpoints.

- `models/efficientnet_b4_ffpp_source.pth`: FaceForensics++-trained source checkpoint used for transfer learning.
- `models/yolo/yolov8n-face.pt`: YOLO face-detector checkpoint.
- `face_detection_yunet_2023mar.onnx`: YuNet fallback face detector.
- DFD and FaceForensics++ media are **not** redistributed.

Before redistribution or commercial use, verify the current licenses and dataset terms for every upstream model and dataset. The hackathon metrics and code do not grant rights to third-party media.
